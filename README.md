# SevenGrip — ecommerce frontend en React

Sitio de catálogo para SevenGrip desarrollado con React y Vite. No incluye carrito, checkout ni backend: cada consulta se deriva a WhatsApp con un mensaje prearmado.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build y deploy

```bash
npm run build
```

Netlify toma la configuración de `netlify.toml` y publica la carpeta `dist`.
